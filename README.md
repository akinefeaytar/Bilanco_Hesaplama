## 🚀 Özellikler

- **⚡ Sıfırdan Başlangıç:** Açılışta tertemiz, sıfırlanmış arayüz; anında veri yüklemeye hazır.
- **📊 Hızlı Mizan İçe Aktarımı:** Excel formatındaki mizanları doğrudan sürükle-bırak veya panodan yapıştırarak saniyeler içinde aktarma.
- **📑 Otomatik Tablolar:** Bilanço (Dönen/Duran Varlıklar, Kısa/Uzun Vadeli Yabancı Kaynaklar, Özkaynaklar) ve Gelir Tablosu otomatik hesaplanır.
- **💵 Çift Para Birimi:** TL ve USD bazlı canlı kur karşılıkları.
- **🎨 Zengin Temalar:** Aydınlık, Koyu ve Zarif Lila tema seçenekleri.
- **📤 Renkli Excel Çıktısı:** Tek tıkla biçimlendirilmiş, sunuma hazır Excel formatında indirme.

## 💻 Geliştiriciler İçin Kaynak Koddan Çalıştırma

Projeyi yerelinizde kod üzerinden çalıştırmak isterseniz:

```bash
# Depoyu klonlayın
git clone https://github.com/akinefeaytar/bilanx.git
cd bilanx

# Bağımlılıkları yükleyin
npm install

# Masaüstü uygulamasını başlatın
npm start
```
